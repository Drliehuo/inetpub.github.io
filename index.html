LPC · LCC 官方主页

PHP 7.4+ MySQL / MariaDB Redis 缓存 PDO 预处理 Bootstrap 3 响应式设计 阿里云 OSS JWPlayer

产品与服务

LPC 共有云

Lighttp Public Cloud · 轻量级共有云内容系统

  • 多租户架构，支持高并发
  • 文章 / 分类 / 标签 / 用户管理
  • Redis 缓存加速，页面响应 < 100ms
  • Bootstrap 3 响应式后台
  • 支持 OSS 对象存储
v1.1.4 最新 · 2026-08-04

LCC 私有云

Lighttp Customer/Private Cloud · 私有内容管理系统

  • 单租户私有化部署，数据隔离
  • 文章密码保护 / IP 白名单 (CIDR)
  • 严格鉴权模式 (token 路径绑定)
  • 附件总库 + 拖拽批量上传 (OSS)
  • 访客统计 / 每日更新追踪
v2.0.5 最新 · 2026-07-12

核心特性

Argon2id 密码加密 Cookie 安全 (httponly, secure) Redis 令牌管理 Admin IP 白名单 文章 IP 白名单 (CIDR) 严格鉴权 (方案B) OSS 签名缓存 Nginx 安全加固 JWPlayer 8.24.3 每日更新任务追踪
