Lighttp

Lighttp（Lighttp Public Cloud）—— 基于 PHP + MySQL + Redis 的轻量级内容管理系统

分类：内容管理 / PHP 更新：2026年8月 作者：Inetpub

项目简介

Lighttp（Lighttp Public Cloud）是一款基于 PHP + MySQL + Redis 构建的轻量级内容管理系统。采用 MVC 架构设计，代码简洁、性能优异、安全可靠，适用于个人博客、企业官网、知识库等场景。

核心特性

  • MVC 架构：清晰的代码分层，便于维护与扩展
  • 高性能：Redis 缓存加持，页面响应迅速
  • 安全可靠：内置 XSS 过滤、CSRF 防护、SQL 注入防御
  • 轻量便捷：代码简洁，部署快速，资源占用低

技术栈

  • 后端：PHP 7.4+ / MySQL 5.7+ / Redis 6.0+
  • 架构：MVC 分层设计

适用场景

  • 个人博客
  • 企业官网
  • 知识库 / 文档站
