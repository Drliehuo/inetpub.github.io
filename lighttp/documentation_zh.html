1. 快速开始

5 分钟即可完成 Lighttp 的安装和首次登录。

1.1 系统要求

组件要求版本
Web 服务器Nginx 1.18+ / Apache 2.4+
PHP7.4 ~ 8.3
MySQL / MariaDB5.7+ / 10.3+
Redis5.0+

1.2 安装步骤

1
上传文件 — 将 Lighttp 所有文件上传到服务器的网站根目录（如 /var/www/html/ 或 public_html/）。
2
创建数据库 — 在 MySQL 中创建一个新数据库（如 lighttp_db），字符集选择 utf8mb4。
3
配置数据库 — 编辑 src/app/config/config.php，填写正确的数据库连接信息：
'database' => [
    'host' => 'localhost',
    'port' => 3306,
    'database' => 'lighttp_db',    // 你的数据库名
    'username' => 'your_user',     // 数据库用户名
    'password' => 'your_password', // 数据库密码
    'charset' => 'utf8mb4',
],
4
导入数据表 — 在 phpMyAdmin 或命令行中导入 install.sql 文件：
mysql -u your_user -p lighttp_db < install.sql
5
设置网站根目录 — 将 Web 服务器的 DocumentRoot 指向 public/ 文件夹。
6
访问网站 — 在浏览器中打开你的域名，看到欢迎页面即表示安装成功！
✅ 安装完成！ 默认管理员账号：admin / 密码：admin123。请立即登录后台修改密码！
⚠️ 安全提示： 安装完成后，建议删除 install.php 和 install.sql 文件，防止被恶意利用。

2. 登录与账户

2.1 登录后台

  1. 在浏览器中访问 http://你的域名/admin
  2. 输入用户名和密码
  3. 点击「登录」按钮
🔐 登录页面示意图
（实际界面以部署后为准）

2.2 修改密码

  1. 登录后台后，点击右上角用户名
  2. 选择「修改密码」选项
  3. 输入旧密码和新密码（至少6位）
  4. 点击「保存」
🔴 重要： 首次登录后请立即修改默认密码（admin/admin123），防止账号被盗。

2.3 用户角色说明

角色权限说明
管理员全部权限：用户管理、系统设置、所有内容管理
编辑内容管理：创建/编辑/删除所有文章和分类
作者仅管理自己的文章
订阅者仅浏览，无管理权限

3. 后台仪表盘

登录后首先看到的就是仪表盘，这里是整个管理系统的核心入口。

3.1 数据概览

仪表盘顶部显示四个关键数据卡片：

  • 📄 文章 — 已发布文章总数
  • 📂 分类 — 全部分类数量
  • 💬 评论 — 已通过审核的评论数
  • 👤 用户 — 注册用户总数

3.2 快捷入口

仪表盘下方提供五个快捷功能卡片：

  • 📄 文章管理 — 进入文章列表
  • 📂 分类管理 — 管理分类
  • 👤 用户管理 — 查看用户列表
  • ⚙️ 系统设置 — 修改网站配置
  • 🗑️ 清空缓存 — 一键清除 Redis 缓存
💡 提示： 仪表盘中的统计数据会实时更新，方便你随时了解网站运营状况。

4. 文章管理

文章是网站的核心内容，Lighttp 提供了完整的文章管理功能。

4.1 文章列表

在 /admin/articles 页面，你可以看到所有文章的列表，包含以下信息：

  • ID — 文章唯一编号
  • 标题 — 文章标题（点击可查看）
  • 分类 — 所属分类名称
  • 状态 — 草稿 / 已发布 / 待审核
  • 发布时间 — 创建日期
  • 操作 — 查看、编辑、删除

4.2 新建文章

  1. 点击「➕ 新建文章」按钮
  2. 填写以下内容：
    • 标题（必填）— 文章标题
    • 摘要（选填）— 文章简短介绍，显示在列表页
    • 分类（选填）— 选择所属分类
    • 内容（必填）— 文章正文，支持 HTML 标签
    • 状态 — 草稿 / 已发布 / 待审核
    • 置顶 — 勾选后文章将显示在列表顶部
    • 推荐 — 勾选后文章将显示「推荐」标记
  3. 点击「发布文章」按钮
✨ 提示： 发布文章后，前台首页会立即显示最新文章。如果启用了 Redis 缓存，可能需要清空缓存才能看到更新。

4.3 编辑文章

在文章列表中点击「编辑」按钮，即可修改文章的所有信息。修改后点击「更新文章」保存。

4.4 删除文章

点击「删除」按钮，系统会弹出确认对话框，确认后文章将被永久删除（不可恢复）。

⚠️ 注意： 删除操作不可撤销，请谨慎操作。建议先将要删除的文章改为「草稿」状态。

4.5 文章状态说明

状态含义前台是否可见
草稿正在撰写中，未完成❌ 不可见
已发布已完成并公开发布✅ 可见
待审核等待管理员审核❌ 不可见

5. 分类管理

分类帮助你将文章组织成不同的主题，方便读者浏览。

5.1 分类列表

在 /admin/categories 页面，你可以看到所有分类：

  • ID — 分类编号
  • 名称 — 分类显示名称
  • 别名 — URL 中使用的友好名称（如 /category/tech）
  • 描述 — 分类简短介绍
  • 操作 — 编辑、删除

5.2 新建分类

  1. 点击「➕ 新建分类」按钮
  2. 填写以下内容：
    • 分类名称（必填）— 如「技术」「生活」
    • URL 别名（选填）— 如 tech，留空自动生成
    • 描述（选填）— 分类的简短说明
  3. 点击「创建分类」按钮
💡 提示： URL 别名建议使用英文小写字母和连字符，如 web-development，有利于 SEO。

5.3 编辑和删除分类

  • 编辑 — 点击「编辑」修改分类信息
  • 删除 — 点击「删除」并确认，该分类下的文章不会被删除，但会变为「未分类」状态

6. 用户管理

查看和管理所有注册用户的信息。

6.1 用户列表

在 /admin/users 页面，你可以查看所有用户：

  • ID — 用户编号
  • 用户名 — 登录用户名
  • 邮箱 — 注册邮箱
  • 角色 — 管理员 / 编辑 / 作者 / 订阅者
  • 状态 — 启用 / 禁用 / 待验证
  • 注册时间 — 账号创建日期
⚠️ 注意： 当前版本暂不支持在后台直接创建或编辑用户，如有需要请通过数据库操作或命令行工具管理用户。

8. 缓存管理

Lighttp 使用 Redis 缓存来提升网站性能，你可以通过后台管理缓存。

8.1 缓存机制说明

  • 页面缓存 — 将完整的 HTML 页面缓存 60 秒，大幅提升访问速度
  • 数据缓存 — 缓存首页文章列表和分类数据 300 秒
  • 缓存命中 — 当用户访问时，系统会优先返回缓存内容
  • 缓存失效 — 新增/修改/删除文章或分类时，相关缓存会自动清除

8.2 手动清空缓存

当发现网站内容没有及时更新时，可以手动清空缓存：

  1. 在仪表盘点击「🗑️ 清空缓存」按钮
  2. 系统会弹出确认对话框，点击「确定」
  3. 所有 Redis 缓存将被清除，网站内容会重新从数据库加载
💡 提示： 清空缓存后首次访问页面可能会稍慢（因为需要重新生成缓存），之后访问会恢复正常速度。
⚠️ 注意： 如果 Redis 服务未启动或连接失败，缓存功能将自动禁用，网站仍可正常运行（但速度会变慢）。

9. 前台使用

了解访客如何浏览和交互你的网站。

9.1 首页

网站首页（/）展示：

  • 导航菜单 — 显示所有分类，登录/注册入口
  • 最新文章列表 — 按发布时间倒序显示，置顶文章优先
  • 管理快捷栏 — 登录后可见，提供快速管理入口
  • 页脚 — 显示版权信息和系统名称

9.2 文章详情页

点击文章标题进入详情页（/article/{id}），展示：

  • 文章标题和完整内容
  • 发布时间、分类、作者、浏览次数
  • 「返回首页」链接
  • 「编辑」和「管理」链接（登录后可见）

9.3 分类页面

点击导航栏的分类名称进入分类页（/category/{slug}），展示该分类下的所有文章列表。

9.4 用户注册与登录

  • 注册 — 访问 /register，填写用户名、邮箱、密码
  • 登录 — 访问 /login，输入用户名和密码
  • 登出 — 点击导航栏的「退出」按钮

10. 常见问题

Q1: 登录后台显示「用户名或密码错误」怎么办？

  • 确认用户名和密码是否正确（默认 admin/admin123）
  • 检查数据库 users 表中是否有该用户
  • 如果忘记密码，可以通过数据库直接修改：使用 password_hash('新密码', PASSWORD_DEFAULT) 生成新密码

Q2: 文章发布后前台看不到？

  • 确认文章状态是否为「已发布」（草稿和待审核状态前台不可见）
  • 尝试清空 Redis 缓存（后台 → 清空缓存）
  • 检查浏览器是否使用了强缓存（按 Ctrl+F5 强制刷新）

Q3: Redis 连接失败怎么办？

  • 确认 Redis 服务是否正常运行：redis-cli ping
  • 检查 config.php 中的 Redis 配置（host、port、password）
  • 如果 Redis 不可用，系统会自动降级，网站仍可运行（性能会下降）

Q4: 如何修改网站 Logo 和样式？

  • Logo 图片可以放在 public/images/ 目录下
  • 修改 public/css/ 中的样式文件
  • 建议在 app/controllers/HomeController.php 中修改前端 HTML 结构

Q5: 网站访问出现 404 错误？

  • 检查 Web 服务器配置，确保 DocumentRoot 指向 public/ 目录
  • 检查 .htaccess（Apache）或 Nginx 的 rewrite 规则
  • 确认路由是否在 routes.php 中正确定义

Q6: 如何备份网站数据？

  • 数据库备份： 使用 phpMyAdmin 导出 SQL 文件，或执行 mysqldump -u user -p lighttp_db > backup.sql
  • 文件备份： 打包整个 Lighttp 目录，重点备份 public/uploads/ 中的用户上传文件

Q7: 如何升级 Lighttp 到新版本？

  • 备份现有网站文件和数据库
  • 下载最新版本代码，覆盖旧文件（注意保留自定义修改）
  • 检查 install.sql 中是否有新增数据表，如有则执行增量 SQL
  • 清除缓存，测试网站功能是否正常
