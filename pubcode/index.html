01简介

PubCode 是烈火团队自主研发并开源的视频编码器。

名字来自 inetpub —— IIS 的默认网站根目录，那个"东西放进去就能被访问"的地方。用意很直白：编码完，直接就能在 Web 上播。

PubCode 在 H.264 / HEVC 这条成熟、兼容性最好的编码路线上，做一件具体的事：

把视频压得更小，同时在低码率下依然播得流畅、干净。

这不是实验室里的指标，是浏览器和移动端能直接看到的结果。

02版本体系

PubCode 目前有两条并行的编码链路，不是简单的新旧替代关系：

版本定位编码音频平台
v1通用 Web，高压缩效率HEVCHE-AACv2通用
v2平台兼容与通用输出H.264AAC LCYouTube / 竖屏短视频
v3快手平台兼容H.264HE-AAC / AAC LC快手

重要说明：v2 与 v3 是并行链路。截至 2026-10-03，v2 链路仍在持续产出（见样本 8）。选型时按目标平台和编码需求决定，不是"越新越好"。

03核心能力

1. 体积小

同样的画面内容，PubCode 编码输出的视频，文件体积明显小于常规编码器。省下来的不只是存储，还有分发带宽。

2. 低码率下流畅播放

低码率场景下依然保持流畅播放，帧间过渡自然，不卡、不顿。

3. 无马赛克

对块效应做了有效抑制。即使码率压得很低，画面依然干净，看不到明显马赛克。

4. 硬件卡编码加速

v3 起支持物理硬件卡编码加速（输出标记 Hw: 1），编码任务可卸载到硬件卡执行，提升吞吐。无硬件卡时自动回退软件编码。

5. 平台适配

  • YouTube：输出参数对齐 YouTube 推荐规格，减少上传后二次转码损失
  • 快手：输出标记 source_type: kuaishou.compatib，适配竖屏短视频场景

6. 按场景动态选择音频

PubCode 的音频编码不是固定值，按目标平台和场景动态选择：

配置码率区间适用场景
HE-AACv251 ~ 54 kb/s低码率优先（v1、1080p 竖屏）
HE-AAC63 kb/s快手（v3）
AAC LC128 ~ 256 kb/s兼容性优先（v2）

06观察与结论

编码路线

  1. v1 用 HEVC，v2/v3 用 H.264。v1 追求压缩效率，v2/v3 为平台兼容性回归 H.264。
  2. Profile / Level 随分辨率自适应：480p ~ 720p 用 L3.1，1080p 用 L5。
  3. 参考帧 3 ~ 5 帧浮动，按内容自适应，5 帧居多。
  4. 帧率模式有 CFR 也有 VFR：样本 6 为 VFR（13.888 ~ 30 FPS），保留源素材不恒定帧率；其余为 CFR。

音频策略

八份样本出现 四种音频配置：

配置出现样本码率
HE-AACv21、851 ~ 54 kb/s
HE-AACv3 链路63 kb/s
AAC LC2256 kb/s
AAC LC3、4、5、6、7128 ~ 192 kb/s

结论：音频按目标平台动态选择。低码率优先场景（v1、1080p 竖屏）用 HE-AACv2；兼容性优先场景（v2 YouTube、v3）用 AAC LC。

码率控制

  • 样本 6、7、8 明确为 VBR。
  • 样本 6、7 走 2pass（rc=2pass），画质/码率控制更精细。
  • 最大码率策略不一：样本 4 设 4 000 kb/s，样本 8 设 3 652 kb/s，样本 2 设 502 kb/s，其余未标。
  • 目标码率与实际码率吻合度高（如样本 6/7 设 bitrate=1000，实际 1 000 kb/s）。

版本标记现状

目前出现 多种编码器标记写法：

写法出现样本
pubcode-v1.10.0.21
x264 core 1652
pubcodev2.2.1.3-202502203、5、8

另有 com.pubcodev1.info / com.pubcodev2.info 两套概览层标记。

建议：统一为 pubcode-vX.Y.Z 格式，保留日期戳，并统一写入概览层 info 字段。

工具差异提示

字段ffprobeMediaInfo
编码函数库不输出输出
编码设置（x264 参数）不输出输出
最大码率常为 N/A输出
数据密度不输出输出
流大小 / 占比不输出输出
MIME 字符串输出不输出
容器 brand / extradata输出不输出
DISPOSITION 全量输出（25 项）部分

采集样本时建议 ffprobe + MediaInfo 各跑一次，避免因工具差异误判为"字段缺失"。样本 8 即为典型：ffprobe 读不到 编码函数库，MediaInfo 读出 pubcodev2.2.1.3-20250220。

封装库版本

encoder 字段出现两种：Lavf58.76.100（多数）与 Lavf62.12.100（样本 2）。建议排查样本 2 链路的封装库版本差异。
