LCC

基于 PHP + MySQL + Redis + 阿里云 OSS 的私有内容管理系统

分类：内容管理 / PHP 更新：2026年8月 作者：Inetpub

项目简介

LCC 是一款基于 PHP + MySQL + Redis + 阿里云 OSS 的私有内容管理系统，专为个人或小团队打造，兼顾功能完整性与部署轻便性。

核心功能

  • 文章发布：支持 Markdown 编辑、分类管理、标签系统、定时发布
  • 附件管理：集成阿里云 OSS，支持图片、文件上传与管理
  • 访客统计：基于 Redis 实现实时访客数据追踪与分析
  • 令牌鉴权：采用 Token 机制保障接口安全，支持多端调用

技术栈

  • 后端：PHP 7.4+ / MySQL 5.7+ / Redis 6.0+
  • 存储：阿里云 OSS
  • 架构：MVC 分层设计，RESTful API

适用场景

  • 个人博客 / 知识库
  • 团队内部文档管理
  • 轻量级 CMS 二次开发
